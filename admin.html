Ownership checklist

The restaurant should own its domain, GitHub repository, Vercel project, Supabase project, and recovery email. Keep account recovery codes securely. Hosting, domain renewals, and database limits remain the owner’s responsibility.

What alerts cover

Orders submitted through this website appear here. WhatsApp messages do not automatically enter the dashboard. Alerts are an original repeating chime, with reconnect checks and a 15-second polling fallback. This is not a guaranteed background alarm service.
